# ARACHNEX '26 — Spider-Verse Symposium Website

A fictional educational demo website created with HTML, CSS and JavaScript.

## Features
- Spider-inspired dark red visual theme
- Animated orbit/web-inspired hero visuals
- Cursor dot and trailing ring effect on desktop
- Interactive card spotlight
- Responsive navigation
- Event cards and schedule
- Registration form with required-field, email and mobile validation
- Reduced-motion accessibility support

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important
All event details, college details, email, phone number and content are fictional placeholders for demonstration. The form is demo-only and does not store data in a backend.
